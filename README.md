# Simple Banking Application using Java

A simple banking system built with Java, Spring Boot, MySQL, and REST APIs. The application provides basic banking operations such as account creation, deposits, withdrawals, fund transfers, transaction history, and user authentication through a browser-based interface.

## Features

* User Registration & Login
* Account Management
* Deposit & Withdraw Money
* Fund Transfer Between Accounts
* Transaction History
* Password Management
* Browser-Based UI

## Tech Stack

* Java 21
* Spring Boot 3
* Spring JDBC
* MySQL
* HTML, CSS, JavaScript
* Maven

## Run the Project

1. Create the MySQL database.
2. Configure database credentials in `application.properties`.
3. Run the application:

   ```bash
   mvn spring-boot:run
   ```
4. Open `http://localhost:8081` in your browser.

## Project Structure

* Controller Layer
* Service Layer
* DAO Layer
* Entity Layer
* Exception Handling
* Static Frontend UI

This project demonstrates CRUD operations, REST API development, JDBC integration, layered architecture, exception handling, and database connectivity using Spring Boot.
